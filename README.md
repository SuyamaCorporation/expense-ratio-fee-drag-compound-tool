# Fund Expense Ratio Fee Drag Compounding Tool

Visualize how annual fund management fees compound over decades and erode portfolio value versus lower-cost index alternatives.

## Features
- Interactive sliders for initial investment, annual contributions, horizon, and gross return
- Side-by-side comparison of high-cost vs low-cost fund growth
- Chart.js line chart showing portfolio divergence over time
- Year-by-year fee impact table with cumulative drag calculation
- localStorage persistence of all settings
- Key insights panel explaining the compounding fee effect

## Usage
1. Set your initial investment and annual contribution amounts
2. Choose your investment horizon and expected gross return
3. Enter the expense ratios for both a high-cost fund and a low-cost index fund
4. View the chart and table to see how fees erode value over time

## Tech
- Tailwind CSS CDN
- Chart.js CDN
- Vanilla JS
- localStorage
